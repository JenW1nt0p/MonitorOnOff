# Changelog

## 1.3

First public release.

- Native menu bar controls for multiple external display outputs.
- Built-in display and last-output protection, UUID tracking, and persistent recovery records.
- Restore outputs on normal quit, with a confirmation if restoration fails.
- Configurable launch at login.
- Automatic language selection for English, Simplified Chinese, Traditional Chinese, Korean, and Japanese.
- MonitorOnOff application icon and universal Apple Silicon / Intel build.

The distributed app is ad hoc signed and is not Developer ID signed or notarized. Display switching uses a non-public macOS interface and depends on hardware and driver support.
